Fondly v0.8.0 — September 17, 2026

GitHub Pages deployment
1. In your current Fondly, export JSON first.
2. Upload index.html, fondly-icon.png, and manifest.webmanifest to the ROOT of the existing GitHub repository.
3. Commit to main. Do not upload your private JSON backup.
4. Keep the same GitHub Pages URL so browser-local data stays associated with the same origin.

v0.8 highlights
- Events + standalone moments are presented together as Socials.
- One Social can be one friend (run/coffee) or a group gathering.
- Existing v0.1-v0.7 data is migrated without deleting IDs or records.
- Navigation keeps an internal back stack so detail pages return to their source view.
- Review is reorganized into Monthly review, Learnings, and Settings.
- Learnings can be revisited as Still true / Unsure / Changed, with review notes preserved.
- Circles still support adding existing or new people directly.
- Mobile viewport remains fixed against accidental pinch zoom; inputs use mobile-safe sizing.

Data remains local to the browser at the exact site address. Export JSON before upgrades or device/browser changes.
